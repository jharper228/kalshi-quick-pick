# Kalshi Quick Picks

A simple Android app that scans Kalshi markets and highlights a small number of potential opportunities.

## Planned Features

- Quick Picks
- Estimated probability and edge
- Risk and uncertainty information
- Market liquidity and fees
- Settlement information
- Full market explanations
- Simulated trading
- Balance and positions
- Buy and review flow
- Secure Kalshi account connection

Quick Picks are estimates and never guarantee profit.

Real-money trades will require explicit confirmation.

Private API keys and passwords should never be stored in the Android app or shared in chat.
